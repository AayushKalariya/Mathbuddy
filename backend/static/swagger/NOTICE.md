# Local API explorer assets

swagger-ui-bundle.js and swagger-ui.css are from the official npm package
swagger-ui-dist, version 5.33.3, published by the Swagger UI project.

Source: https://github.com/swagger-api/swagger-ui
Package: https://www.npmjs.com/package/swagger-ui-dist/v/5.33.3

The upstream LICENSE and package.json are retained here. These assets support
the local developer API explorer; they are not the future writing workspace.

They are committed locally so testing the API explorer does not depend on a CDN.
No npm build or runtime installation is required for using the checker.
